Ôn lý thuyết và viết lại thuật toán

Đọc ý chính → tự viết hàm → chạy ví dụ nhỏ bằng Python hoặc Julia.

Chọn một ngôn ngữ để làm bài.

Mẫu WordCách chạy code
Cách học mỗi bài
  1. Ôn định nghĩa hoặc công thức, tự dự đoán kết quả ví dụ.
  2. Sao chép khung code, thay TODO bằng thuật toán mình viết.
  3. Chạy ví dụ đã có trong code và ghi kết quả, giải thích ngắn.

Dữ liệu nhỏ được viết ngay trong đề hoặc mã: không cần tải, đọc CSV hay chuẩn bị tập dữ liệu. Đây là bản ôn tập rút gọn theo các chủ đề của bài giảng.

Nhắc nhanh cú pháp và quy ước

Cây rỗng cao 0, lá cao 1. BST dùng khóa phân biệt. Hàm trả gốc mới thì gán lại gốc.

Python
def f(x):
    return x
g = None
if g is None:
    pass
a = [1, 2, 3]   # Chỉ số: 0, 1, 2
a.append(4)
Julia

    return x
end
